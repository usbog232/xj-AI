## 需要使用者完成的首次真实设备验证

自动化没有代替用户接受 macOS 麦克风、语音识别和屏幕录制权限。测试时 `127.0.0.1:11434` 没有运行 Ollama，因此界面正确显示连接失败；真实模型回包仍需在模型服务启动后验证。

| 场景 | 前置条件 | 期望 |
| --- | --- | --- |
| 麦克风 | 授权麦克风与语音识别 | 波形变化，出现原文分段 |
| 系统音频 | 授权屏幕与系统音频录制 | 播放视频时出现原文分段 |
| 指定应用 | 目标应用正在播放声音 | 只采集所选应用 |
| 本地翻译 | Ollama 或 llama.cpp server 已启动并有模型 | 约 3 秒分段后补充译文 |
| 局域网翻译 | Base URL 指向可访问的 LAN `/v1` 服务 | 获取模型、连接测试与翻译成功 |
| 云端翻译 | DeepSeek/OpenAI API Key 有效 | Keychain 保存密钥，翻译成功 |
| Apple 语音识别 | 选择 Apple 自带识别并授权 | 设备端累计文本稳定分段，不上传音频 |
| 本地 Whisper | 下载 Tiny/Base/Small Q5 后选择 | 固定时长离线分段，停止时提交剩余音频 |
| 局域网 ASR | 可信 LAN 服务提供 OpenAI transcription 或 whisper.cpp `/inference` | WAV 分段发送到配置地址并按顺序返回原文 |
| 自动保存 | 开关开启 | Records 中出现 JSON 与 CAF |
| 不自动保存 | 开关关闭 | 停止后清理临时音频，不落会话文件 |
| 字幕下载 | 选择记录和原文/译文/双语 | 生成所选 TXT/VTT/SRT 并在 Finder 中显示 |
| 音频下载 | 选择包含本地录音的记录 | 生成所选 MP3/WAV；无音频记录被提示并跳过 |
