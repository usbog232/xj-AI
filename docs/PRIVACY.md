# xj-AI 隐私说明

xj-AI 的设计目标是让音频与文本处理尽可能留在用户设备上。

## 默认行为

- 音频采集由 macOS AVAudioEngine 或 ScreenCaptureKit 完成；
- 语音转文字默认使用 Apple 设备端识别；用户也可主动选择本机 Whisper 或自己配置的局域网 ASR，不会静默切换引擎；
- 翻译默认发送到 `http://127.0.0.1:11434/v1` 的本机 Ollama；
- 会话、音频与字幕写入用户本机选择的记录目录；
- 没有账号系统、遥测、分析 SDK、广告或后台上传。

## Provider 与网络地址

设置允许添加本机、局域网或云端 OpenAI 兼容 Provider。若用户选择局域网、DeepSeek、OpenAI 或其他互联网地址，待翻译文本会发送到该地址；音频不会随翻译请求发送。

若用户主动选择“局域网语音识别”，xj-AI 会把 16 kHz WAV 音频分段发送到用户填写的 ASR 地址。界面会明确显示“音频离开本机”，不会自动回退到局域网或云端。xj-AI 无法保证用户自行配置服务器的隐私与保留政策。

API Key 使用 macOS Keychain 保存，不写入 UserDefaults、会话 JSON、日志或导出字幕。

## macOS 权限

- 麦克风：仅在选择麦克风并开始录音时使用；
- 语音识别：仅在选择 Apple Speech 时用于设备端转写；本地 Whisper 与局域网 ASR 不需要该权限；
- 屏幕与系统音频录制：仅在系统音频或指定应用采集时使用；xj-AI 不保存视频画面。

权限可随时在 macOS `系统设置 → 隐私与安全性` 中撤销。
